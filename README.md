#### 我做事的方式

- **先定位，再动手**：拆资料、拆访谈，找到真正卡住人的那一步，不先写功能
- **判定不交给模型**：需要「确定」的判断用纯函数规则引擎，模型只负责改写与 OCR
- **用评测说话**：建评测集、校准判分、重复取值报区间，按实测结果决定保留还是删掉
